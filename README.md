# Zyphix – Neptun SMP custom crystal plugin

Target: Paper 1.21.4, Java 21.

## Build

The project is built with Maven. Push it to GitHub and open **Actions → Build Zyphix**. Download the `Zyphix-Plugin` artifact (JAR) and install it in `plugins/`.

## Resource pack (required for the custom appearance)

Minecraft clients need a resource pack to display custom item textures/models. Upload the contents of `resourcepack/` as a ZIP to a direct-download host, then configure that pack as your server resource pack in `server.properties` (resource-pack URL and SHA-1). The included model uses custom model data 10001–10004 and the texture extracted from the supplied Zyphix concept image. Without the pack, the item still works but looks like an amethyst shard.

## Commands

- `/zy spawn` – creates a small group of naturally generated Zyphix crystals in front of the admin.
- `/zy undo` – removes the last group created by that admin.
- `/aci` – opens the admin editor.
- `/aci create <id>` – saves the item currently held in the main hand as a custom item.
- `/aci recipe <id>` – opens a 3×3 recipe editor. Drag ingredients into the grid and click **Save recipe**. The recipe is shapeless in this first version.
- `/aci name <id> <MiniMessage>` – changes the saved custom item's name.
- `/aci delete <id>` – deletes an item and its saved recipe.
- `/aci list` – lists custom item IDs in chat.
- `/ci` – public custom item catalogue.
- `/cn <MiniMessage>` – renames the item in your main hand using full MiniMessage syntax, including long gradients.

In `/aci`, drag an item from your inventory into the center input slot and click **Save item**. IDs are generated automatically (`custom_1`, `custom_2`, ...). Use `/aci recipe <id>` to configure its recipe.

## Zyphix mechanics

- Right-click a block while holding a Zyphix item to place it.
- The placed crystal is represented by an invisible barrier collision block and an ItemDisplay carrying the custom 3D model.
- It grows through four visual stages and emits small pale particles rising upward.
- Crystals generated by `/zy spawn` have a 25% drop chance. Player-placed crystals have a 100% drop chance.
- The plugin stores crystal locations in `plugins/Zyphix/config.yml`.

## Important implementation notes

- This is a standalone plugin and does not modify NeptunCore.
- The current recipe editor saves shapeless recipes. The 3×3 positions are used as ingredient input slots, but their exact pattern is not preserved yet.
- The resource pack is required for the exact custom model/texture. A plugin JAR alone cannot force a client to render a new texture.
- Test on a backup/test server first. This build has not been compiled in this environment because Maven is unavailable here; GitHub Actions performs the build.
